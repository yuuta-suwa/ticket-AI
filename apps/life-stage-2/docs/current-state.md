## 2. 画面と遷移
URLによるルーティングはありません。画面の状態は `localStorage` の `ls2.ui`（tab / view / course）で管理しています。
- ログイン画面（パスワード／メールリンク／パスワード再設定）
- 下部ナビ：ホーム／ジャーニー／AI／ブック／マイページ
- 全メンバー向け：7ステージ（1問ずつ回答 → 下書き → 承認 → ブック）、対話練習5場面、3分でできる一歩
- コアメンバー向け：90日（3フェーズのチェック）、90日目標・KPI（差・進捗率・日割りを計算）、実践ログ（メンターの見解3択を含む）、フェーズレビュー、90日の成長記録ブック
- AI：記録から依頼文を作成してコピー、回答の貼り戻しメモ。システムAIボタンは `aiEnabled` が true の時だけ表示（現在 false）
- マイページ：表示名、パスワード、ログアウト、JSON書き出し、管理者向けのロール変更

## 3. ログイン・権限への依存
| 箇所 | 依存の内容 |
|---|---|
| `boot()` | セッションがなければログイン画面を表示。画面全体がログインを前提にしている |
| `loadRemote()` | `ls_profiles.role` で member / core / admin を判定。コアタブの表示はこの結果で決まる |
| `pushRemote()` | `ls_work` への保存。版番号で他端末との競合を検出 |
| `ls2.cache.<uid>` | 未保存分の端末内キャッシュ（ユーザー別） |
| 管理 | `ls_set_role` の呼び出しと、全プロフィールの一覧表示（管理者のみ） |
| URL | メールリンク・パスワード再設定は `?code=`（PKCE）付きで同じURLに戻る |

## 4. 保存先
- サーバー：`ls_work`（ユーザー×program＝all/core の JSON）、`ls_profiles`（表示名・ロール）
- 端末内：`ls2.ui`、`ls2.cache.<uid>`（最後にログインした人の記録の写し）、`sb-xltholkcsbfkbqhnthrr-auth-token`（ログインのセッション）
- さらに古いローカル試用版：`ls2.local`、`lifestage2.v1`（使われていた場合のみ）
