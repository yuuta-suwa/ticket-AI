# LIFE STAGE 2.0 ワーク（試作版 v0.1）

1つのアプリで「全メンバー向け」を基本とし、上部タブから「コアメンバー向け」ワークを開けます。
ビルド不要の静的Web/PWA（`index.html` 1ファイル＋manifest/sw/icon）。

## 構成
| 区分 | 内容 |
|---|---|
| 共通 | ダークネイビー #101A2E ＋ シャンパンゴールド #C7AA70、下部ナビ（ホーム／ジャーニー／AI／ブック／マイページ）、自動保存表示（保存中／保存済み／未保存・再試行）、短いオープニング（スキップ可・動き軽減対応） |
| 全メンバー | 7ステージ（MY LIFE VALUE〜THE NEXT CHAPTER）を1問ずつ入力→成果物下書き→本人承認→ブック収録。90秒ストーリーの字数・秒数目安、対話練習シナリオ5種、「3分でできる一歩」 |
| コアメンバー | アクセスコードで開く90日プログラム（3フェーズのチェック）、90日目標・個人KPI（差・進捗率・残り日割りをプログラム計算）、実践ログ（仮説→実践→結果→メンター見解[同意/一部修正/異議]→次の行動）、フェーズ別レビュー |
| AI | 試作はルールベース（事実／仮説／未確認／次の行動 に分けて提示）。自動投稿なし |
| ブック | 承認済み章／90日成長記録をブラウザ印刷でPDF保存 |

## ローカル確認
```
cd apps/life-stage-2 && python3 -m http.server 8080   # http://localhost:8080
```
コアメンバー試作コード：`CORE2026`（`index.html` の `CORE_CODE_DEFAULT`）

## 公開前に必ず対応すること（試作の制約）
1. **コア権限はクライアント側判定のみ**。コードはソースから読めるため、本番は認証＋サーバー側の受講権限チェックに置き換える。
2. **保存は端末のlocalStorageのみ**。端末間同期・バックアップ・メンター共有／撤回はサーバー実装が必要（マイページにJSON書き出し/読み込みあり）。
3. **AIはルールベース**。サーバー側AI接続（教材参照・利用上限・個人データ送信範囲）を実装する。
4. PDFはブラウザ印刷依存。日本語PDF生成ジョブは後続。
5. 教材本文は仕様書の構造から作成した暫定文。教材責任者の確認が必要。
6. 実機（iOS/Android）での表示・文字拡大・スクリーンリーダー確認。

## 公開方法（静的ホスティング）
このフォルダをそのまま Vercel / Netlify / GitHub Pages / Cloudflare Pages に配置するだけで動作します（HTTPSでService Worker有効）。
