# 改訂した業務フロー
2026-10-24。旧「商品を決めて受注する」手順から、AIによる事業探索へ改訂。

| 工程 | 担当 | 次へ進む根拠 |
|---|---|---|
| 会社方針 | 本人、AIが設定案を作成 | 許可資金・対象・操作・禁止領域 |
| 課題探索 | マーケティング | 原本、顧客課題、既存代替、反証 |
| 事業案 | 商品開発とマーケティング | 解決策、提供形式、課金方式、販路、維持負担 |
| 実験選択 | AI社長・経理・品質 | 事前登録した指標・期限・最大損失・停止条件 |
| 試作・小規模提供 | 開発・営業機能 | 利用可能な機能、適切な相手の実反応、許可範囲 |
| 限定販売・公開 | 実行アダプター | 本人の方針内、現行版、費用予約、接続先確認 |
| 運営・改善 | 運営、経理、商品開発 | 購入、使用、継続、返金、全費用、介入時間 |
| 追加投資・停止 | AI社長と資金制御 | 実績と維持責任。範囲外は本人判断 |
| 撤退処理 | 運営・経理 | 顧客対応、課金・契約終了、残存請求、データ処理 |

各段階は実装済みの宣言ではなく、改訂後の業務契約。詳細はAUTONOMOUS_BUSINESS_SPEC.md、受入はIMPLEMENTATION_ACCEPTANCE.md。
通常の企画選定はAIに任せ、本人を全件承認のボトルネックにしない。
原価上限の追加、未知結果、重大障害、対象外契約等だけを本人へ上げる。
