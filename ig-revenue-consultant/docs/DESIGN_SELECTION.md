# 採用デザイン：STRATEGY ATELIER

2026年11月1日、ユーザーが会話に表示した2番を選択。対応画像は `reference/design/strategy-atelier.png`。この方向で確定し、他の2案は比較参考としてのみ残す。再選択を求めず実装に進む。

- 深いチャコールを基調に、アイスブルーを主要操作、銅色を限定的な強調へ用いる。
- 中央は「視聴者の課題 → 届ける価値 → 報酬成立条件」の編集できる戦略キャンバス。仮説と確認済み事実を明示する。
- 右側に、現在の相談文脈と根拠に沿ったAIの助言を置く。
- 主題は「今日、変えるのはこのひとつ。」。再訪時は大きな紹介写真より最優先施策と判断根拠を優先する。
- モバイルは戦略の要点→次の一手→根拠→相談の順に再構成し、横3列を縮小しない。
- 本物のReact UIで実装する。画像を背景として貼り付けない。本文16pxを基準に、コントラストと操作性を検証する。

これはClaude向けの採用指示。新デザインの実装・本番反映は未実施。
