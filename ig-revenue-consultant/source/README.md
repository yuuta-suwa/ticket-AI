# IG Revenue Consultant — STRATEGY ATELIER（v3）

深いチャコール・アイスブルー・銅色の「STRATEGY ATELIER」デザインで、Instagram収益化の専属コンサル体験へ刷新しました。主要ナビは5つ（戦略ルーム／相談室／収益戦略／投稿と検証／設定）。

- **初回ヒアリング**：目的・強み・相手・実行できる範囲・データ状況の5段階。各段階で保存し、中断しても再開できる。
- **戦略ルーム**：「今日、変えるのはこのひとつ。」最優先の施策1件、判断の根拠と未確認点、戦略キャンバス（視聴者の課題→価値の届け方→報酬が生まれる条件）、AIの視点。主要CTAは1つ。
- **相談室**：相談セッションとターンを保存。提案は相談レポートv2（結論→理解した状況→根拠→仮説→施策→反証→次の判断）。採用・保留・選ばないを理由付きで記録し、採用は施策の下書きへ（同じ提案から二重作成しない）。
- **検証ループ**：施策に事前の予測・観察結果・判断（継続/修正/中止/観察延長）と理由を残す。提案の作成時点のデータ版と現在の記録が違えば「古い提案」と表示し、再診断を促す。
- **AIの実行モードを区別**：ルール診断（無料・生成AIではない）／外部AIの結果取り込み（参照IDと金額を検証）／Claude API（有料・明示的な有効化、日次回数と月間トークンの上限）。

詳細は `../docs/BUILD_PROGRESS.md`、移植判断は `../docs/PORTABILITY_DECISION.md`。

# Instagram Revenue OS

Instagramを入口に、視聴者への価値と確定収益を検証する個人用Webアプリ。日本語UI、ChatGPTのサインイン、ユーザーごとのD1保存、Claude APIによる実際の生成AI分析に対応しています。

## 最初に使う流れ

1. 公開されたアプリへChatGPTでサインインする。
2. 「設定・接続」にテーマ、届けたい相手、運用時間、工数評価額を登録する。
3. 「収益源ラボ」で支払者と価値を設定する。ギフト、協賛、購入以外の送客成果、素材利用料、広告収入など12種類を比較できる。候補の追加では利用資格が成立したことにならない。
4. 調査資料・本人が確認した観察を記録し、ひとつの仮説を実験する。
5. 投稿を作り、全文・素材・事実・権利・広告表示を確認して承認する。手動投稿のURLを記録するか、公式API接続後に公開する。
6. 報酬・費用・投稿指標・実験結果を更新する。生成AIの改善案を次の実験や投稿の下書きへ引き継ぐ。

上部の再生ボタンで、架空データを使うデモを試せます。デモはブラウザーのメモリーだけに存在し、外部への公開・クラウドへの実績保存を行いません。再読み込みで消えます。

## 生成AIと自動改善

「設定・接続」でClaude APIキーを登録します。接続確認はモデル一覧の取得だけを行い、文章生成はしません。生成AIを使うにはAPIの有料実行と1日の回数上限を明示的に設定してください。初期設定は無効・0回です。個人向けClaudeの会費とAPI料金は別です。

「実績の保存後にAI改善分析を自動実行する」を有効にすると、報酬・費用、投稿指標、実験結果の変更に応じて、実際のClaude APIが改善レポートを作成します。同じ実績の自動分析は一意なジョブで重複を防ぎ、日本時間の日次回数上限を適用します。失敗した呼び出しも回数に含みます。自動分析ではWeb検索を使用しません。分析に失敗しても実績の保存は完了し、再実行方法を表示します。

この方式の学習は、実績・反証・判断履歴・利用者の評価を次回のプロンプトへ渡すものです。モデル自体の追加学習や、成果が確実に改善することを意味しません。レポートは提案であり、実験と投稿の実行は人が判断します。

APIキーなしでも、登録データ付きのプロンプトをコピーしてChatGPT等で実行し、指定JSONの結果を取り込めます。「登録データの診断」は明示的な条件分岐であり、生成AIと区別して表示します。

手動の生成AI実行では、任意でClaudeのWeb検索を最大3回使えます。実際に提供元から返った検索結果のみ出典として保存します。入力した資料、投稿、実績が提供元へ送られるため、不要な個人情報は登録しないでください。

## Instagram公式接続

対応は **Instagram Login方式のプロアカウント用アクセストークン** です。Facebook Login方式や旧Basic Displayのトークンは対象外です。Metaアプリで自分のアカウントを接続し、必要な権限を付与したトークンを設定画面に入力してください。

- 接続時：アカウントID・ユーザー名を確認。
- 同期時：直近12件の投稿、取得できた再生数・リーチを記録。権限等により取得できない指標は「未取得」。クリック・外部の成果は別途記録する。
- 公開時：承認済みの画像フィードまたはリールを、登録した完成素材のHTTPS URLから公開。処理中のコンテナを再利用し、結果が不明な場合は再送を止める。
- 条件が満たせない投稿形式は、手動投稿と公開URL記録を使用する。
- トークンの期限更新は再接続で行う。自動更新・Meta OAuthの画面は未実装。

Metaアプリの審査・権限・アカウント資格・メディア仕様は利用者側で成立する必要があります。一般的な「接続済み」表示と、各機能の取得・公開成功は別に扱います。完成素材のURLは承認対象に含みますが、外部ホスト上のファイル自体を固定するものではありません。承認と公開の直前に実物を確認してください。

公式資料：

- https://developers.facebook.com/docs/instagram-platform/instagram-api-with-instagram-login/
- https://www.postman.com/meta/instagram/documentation/6yqw8pt/instagram-api
- https://platform.claude.com/docs/en/api/messages/create
- https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool

## 収益の集計

通貨は日本円・税抜の管理用集計です。確定・入金済みの報酬だけを収益に含め、見積り・承認待ち・否認と区別します。減額は元の確定報酬へ紐付け、戻らない手数料と発生済み原価は残します。利益は登録した原価・工数に限る暫定値です。未記録の費用が0円だったと断定しません。

CSVは共通テンプレートで明細を追加し、収益源・明細種別・外部明細IDで重複を防ぎます。既存明細の状態は自動で上書きしません。承認・入金の更新は編集画面から行います。これは会計・税務申告システムや決済システムではありません。

## 安全性と保存

- Hosted Sitesの認証を利用し、APIは利用者IDで所有データを絞り込む。
- 更新APIは同一Originとログインを必須にし、版番号の比較で更新競合を拒否する。
- APIキー・トークンはサーバーのAES-GCMで暗号化し、利用者・接続先を認証データへ含める。画面・JSONバックアップへキーを返さない。
- 投稿本文・構成・素材URL・根拠・収益条件の変更で承認を失効させる。公開済み記録は通常の保存・復元で書き換えない。
- 停止スイッチは新規の有料AI分析、API公開、新しい実験開始を止める。実行済みの外部操作は取り消さない。
- JSONバックアップの復元はキーを含まず、有料AIと自動分析を無効に戻す。新しい投稿の承認・公開状態は復元だけでは成立しない。

## 現在の範囲

本版は要件定義の最初の実装です。実績更新時の自動分析を含む、調査→実験→投稿承認→報酬照合→改善提案の運用を実装しています。詳細な構想は [要件定義](docs/requirements-v1.1.md) を参照してください。

定時の巡回取得、アプリを操作していない間の実行、予約公開、無人の投稿・契約・DM、問い合わせCRM、決済・注文・納品の統合、素材生成・動画編集、モデルの追加学習は含みません。収益構造の新案は仮説として比較し、実需や報酬成立を保証しません。モデル・API・外部素材を含む完全な本番連携試験は、実際の接続資格情報を登録した後に必要です。

## 開発と検証

Vinext / React / TypeScript / Cloudflare Workers / D1 / Drizzle。起動・ビルドにはNode.js 22.13以降とpnpmを使用します。ホスティング設定は `.openai/hosting.json` にあります。Sitesの公開パイプラインが生成済みDrizzleマイグレーションを適用します。

ランタイムに必要な秘密情報は `CREDENTIAL_ENCRYPTION_KEY`（ランダムな32バイトをBase64化した値）です。ソース、ブラウザー、公開アーカイブに値を入れないでください。再生成すると既存の接続を復号できなくなるため、通常の更新では同じ鍵を維持します。

```sh
node node_modules/typescript/bin/tsc --noEmit
node --experimental-strip-types --test tests/domain.test.mjs
python tests/persistence_test.py
pnpm lint
pnpm build
```

金額照合・承認・CSV等の14件、DBの利用者分離・競合・実行回数・ジョブ重複の3件を検証しています。固定の架空会計条件で運用貢献利益24,300円を照合しています。デスクトップ画面、390px幅のメニュー、デモの明細追加と診断作成をブラウザーで確認しています。実際のAPIキー・Instagramアカウントを使った有料生成・投稿は、この構築時には実行していません。
