# 通常のClaudeチャットで始める場合

採用デザインは **STRATEGY ATELIER（会話で表示した2番）** に確定。`docs/DESIGN_SELECTION.md` と `reference/design/strategy-atelier.png` を実装の基準とする。他の案への再選択は不要。

添付の引き継ぎ一式を読み、Instagram収益最大化AIコンサルの新しい相談体験を、見て操作できるWebプロトタイプとして作成してください。Code実行環境がある場合は `00_CLAUDE_CODE_START_PROMPT.md` を優先します。

目的は、管理画面の色替えではなく、専属コンサルに状況を理解してもらい、根拠と仮説を見ながら次の施策を決められる体験です。採用済みの `reference/design/strategy-atelier.png` を基準に実装してください。

主要な画面：短い初回ヒアリング、戦略ブリーフ、AI相談、根拠ノート、施策の下書きと検証、収益戦略の比較。

まずフロントエンドだけで相談→提案→施策下書きまで触れるものを作る。データは明示した架空のデモとして扱い、元データと混ぜない。接続していないAPI、売上、AI実行、Instagram公開が動くように装わない。既存の認証・DB・外部APIがチャットのArtifactへそのまま移せるとは説明しない。未実装は未実装と表示する。

余白、本文16px、明確な主要CTA、根拠/仮説の区別、モバイルでの読みやすさを重視。大量のKPIカード、AI球体、過剰なガラス表現、架空の成長率や点数は禁止。

コードと、Claude Codeで本番化するために必要な差分を提出してください。サンプルの画面ができたことと、本番接続が完了したことは分けて報告してください。
